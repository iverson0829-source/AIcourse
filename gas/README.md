# 煎時 JIANSHI 線上訂單 × Google 試算表（Apps Script）

網站結帳送出後，訂單會寫進 Google 試算表，並自動寄出 Email 通知。

```
網站結帳 ──POST──▶ Apps Script 網頁應用程式 ──▶ Google 試算表（訂單／訂單明細）
                         │
                         ├─▶ 顧客確認信、店家新訂單通知（Gmail）
                         └─▶ 每晚 21:30 營業報表
```

## 功能一覽

| 功能 | 說明 |
| --- | --- |
| 自動建表 | 建立「訂單」「訂單明細」「菜單價格」三個工作表，含表頭、格式、狀態下拉選單與顏色 |
| 伺服器端算錢 | 依「菜單價格」重算金額與運費，網頁上的價格被竄改也沒用；改價直接改試算表 |
| 訂單編號 | 每日流水號 `JS251127-001`，同時下單也不會重號 |
| Email 通知 | 顧客有填 Email 就寄確認信；店家每張新訂單都會收到通知 |
| 訂單狀態 | 「狀態」欄可選 新訂單／製作中／可取餐/已出貨／已完成／已取消，改動時自動記錄時間 |
| 每日報表 | 每晚寄出當日有效訂單數、營收、平均客單、熱銷前 5 名 |
| 訂單查詢 API | `?action=status&orderNo=JS…&phone=09…` 回傳訂單狀態（需訂單編號＋手機同時正確） |
| 基本防護 | 防機器人隱藏欄位、同手機 10 分鐘最多 5 張、重送不重複建單、防試算表公式注入 |

## 部署步驟（約 10 分鐘）

### 1. 建立試算表與程式
1. 到 [Google 試算表](https://sheets.new) 建立新試算表，命名例如「煎時線上訂單」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把 `Code.gs` 的內容整個貼上，取代預設程式碼。
4. 左側齒輪 **專案設定** → 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」，回到編輯器，把 `appsscript.json` 內容貼上取代。
5. 視需要修改 `Code.gs` 最上方的 `CONFIG`（例如 `NOTIFY_EMAIL` 填店家收信信箱）。按 💾 儲存。

### 2. 初始化
1. 編輯器上方函式選單選 **setup** → 按「執行」→ 依指示授權（會出現「Google 尚未驗證這個應用程式」，點「進階 → 前往（不安全）」，這是你自己的程式）。
2. 再選 **installTriggers** → 執行。
3. 回到試算表重新整理，上方會多一個「🥟 煎時訂單」選單。

### 3. 部署為網頁應用程式
1. 編輯器右上 **部署 → 新增部署作業** → 類型選「網頁應用程式」。
2. 執行身分：**我**；誰可以存取：**所有人**。
3. 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。

### 4. 接上網站
打開 `index.html`，搜尋 `const ORDER_API = '';`，把網址貼進引號裡：

```js
const ORDER_API = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

留空時網站會維持「示範模式」（可完整操作，但不會寫入試算表）。

## 之後要修改程式
改完 `Code.gs` 後要 **部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**，網址不變，網站不用改。

## 常見問題
- **改了菜單價格要做什麼？** 直接改「菜單價格」工作表即可，立即生效。網站上顯示的價格在 `index.html` 的 `MENU`／`GIFTS`，記得同步修改。取消勾選「供應中」＝下架。
- **新增品項？** 在「菜單價格」新增一列（品項ID 要和網站 `MENU` 的 `id` 一致）。
- **Email 寄送上限？** 一般 Gmail 帳號每天約 100 封，Google Workspace 約 1,500 封。
- **測試 API 是否正常？** 用瀏覽器開啟網頁應用程式網址，看到 `{"ok":true,...}` 就代表部署成功。
